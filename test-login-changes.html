Sistema de Login Actualizado
  • Login con Username: Ahora se usa el nombre de usuario en lugar del email
  • Username Único: Los nombres de usuario no pueden repetirse
  • Validaciones: Username debe tener 3-50 caracteres, solo letras, números, - y _
  • Email separado: El email se valida por separado para verificación
Para probar:
  1. Ve a login.php
  2. En la pestaña "Iniciar Sesión" verás que ahora pide "Nombre de usuario"
  3. En la pestaña "Registrarse" el username ahora tiene validaciones estrictas
  4. Intenta registrar un usuario con un username que ya existe - debería dar error específico
  5. Intenta registrar con un email que ya existe - debería dar error específico
